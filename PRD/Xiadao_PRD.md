# 虾道 (Xiadao) / Kanne Canvas 项目需求分析文档 (PRD)

## 1. 项目背景
本项目目前代码中称为 **Kanne Canvas**，但根据历史记录，项目正处于更名为 **虾道 (Xiadao)** 的过程中（目前代码中仍可见 Kanne Canvas 字样）。这是一个轻量级的本地化图像生成平台，旨在为用户提供便捷的 AI 生图能力。

## 2. 核心功能需求

### 2.1 图像生成 (Text-to-Image)
- **提示词输入**：用户可以输入详细的提示词（Prompt）来指导 AI 生成图像。
- **参数控制**：
  - **尺寸 (Size)**：支持多种尺寸选择（如 1024x1024, 1792x1024, 1024x1792 或自动）。
  - **质量 (Quality)**：支持 high, medium, low 等质量等级。
  - **格式 (Format)**：支持 png, jpeg, webp 导出格式。
  - **数量 (Count)**：单次可生成 1-4 张图片。
- **模型选择**：默认支持 `gpt-image-2`，用户可自定义模型名称。

### 2.2 参考图支持 (Image-to-Image / Reference)
- **图片上传**：支持将本地图片拖入或点击上传。
- **公网 URL**：支持粘贴公网图片链接作为参考图。
- **参考图叠加**：支持多张（最多4张）参考图联动生成。

### 2.3 API 与集成
- **多米接口集成**：代码中实现了针对 `duomiapi.com` 的深度适配，支持异步任务提交与自动化状态轮询。
- **自定义 Base URL**：支持用户配置符合 OpenAI 标准的自定义 API 转发地址（V1 接口）。
- **安全性与 Key 管理**：出于安全考虑，**前端 UI 将完全移除 API Key 的输入与本地保存功能**。API Key 将统一配置在后端（服务端），前端仅负责向后端发起请求，由后端安全地注入 Key 并完成向 AI 接口的请求代理与转发。

### 2.4 历史记录与预览 (History & Gallery)
- **成片墙**：生成后的图片大图预览。生成图片完整显示，避免裁剪（Object-fit contain）。
- **历史流**：下方显示最近生成的历史记录，支持点击回溯预览。点击历史记录时仅进行预览切换，保持历史生成顺序不变（引入 selectedHistoryId 状态），提升操作直观性。
- **大图画廊**：点击图片卡片可全屏预览图片，导航箭头固定，优化各种屏幕尺寸下的浏览体验。
- **数据本地化**：生成历史与 API 设置均保存在本地浏览器中。

## 3. 技术方案分析

### 3.1 前端架构
- **核心框架**：React + TypeScript。
- **构建工具**：Vite。
- **UI 设计**：采用 Vanilla CSS，具备磨砂玻璃效果、动态光球背景（Orb animations）等现代美学设计。
- **图标库**：使用 `lucide-react` 提供的高质量图标。

### 3.2 接口交互逻辑
- **同步/异步适配**：针对多米 API 自动切换到“提交任务 + 定时轮询”模式；针对普通接口则实时等待响应。
- **错误处理**：具备完善的 HTTP 错误解析与业务错误提示逻辑。

## 4. 待优化点/改进建议
- **品牌一致性**：目前代码中的品牌标识（如 logo 图标路径、文本描述）仍有 "Kanne Canvas" 的残留，需统一更名为“虾道”。
- **文件存储**：由于目前是纯前端项目，参考图上传依赖于一个未定义的 `/upload.php`（或本地模拟），在纯静态部署环境中可能失效。
- **模型定义**：目前 `gpt-image-2` 可能需要更灵活的列表展示，而不仅仅是文本框输入。
